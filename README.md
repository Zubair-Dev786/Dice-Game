# Dice Game 🎲

A simple Dice Game built with **HTML, CSS and JavaScript**.

## 🚀 Features

* Score tracking
* Win condition at 30+ score
* Lose condition when 1 appears
* Reset game functionality
* SweetAlert messages

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* SweetAlert2
